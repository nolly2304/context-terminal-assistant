# Iteration retrospectives

One short file per two-week iteration (e.g. `2026-11-13-iteration-0.md`), written on the last day. These feed the reflective section of the final report (PDD section 11.3).

Template:

```markdown
# Iteration N (start – end)

Planned: backlog items and objective(s)
Done:
Slipped, and why:
What I'd change next time:
Supervisor feedback this iteration:
Hours spent (approx.):
```
