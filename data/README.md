# data/

Everything in this folder except this README is ignored by Git. Datasets are
downloaded locally and never committed (see the ethics section of the PDD).

| Folder | Dataset | How to get it | Licence |
|---|---|---|---|
| `raw/schonlau/` | Schonlau et al. (2001) masquerade data: 50 users × 15,000 commands | `scripts/fetch_schonlau.sh` | Public research data |
| `raw/svabensky/` | Švábenský et al. (2021) shell commands from hands-on cybersecurity training | Download `1. commands.zip` from [Zenodo 10.5281/zenodo.5137355](https://zenodo.org/records/5137355) and unzip here | CC BY 4.0 |
| `raw/greenberg/` | Greenberg (1988) traces of 168 csh users | Requires written permission from Saul Greenberg | Restricted |
| `own/` | My own shell history | Exported locally; never shared | Private |
